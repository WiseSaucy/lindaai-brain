Frequently Asked

What is LindaAI?

LindaAI is an AI Operating System for business owners. It's a collection of 115 pre-built business skills across 8 industry packs, 18 specialist AI agents, voice personalities, and a Discord mobile bridge — all packaged to install into Claude Code with one command. Built by Daniel Wise for entrepreneurs who'd rather get results than configure software.

Is this a subscription?

No. One-time payment per tier. Lifetime access. No monthly traps.

Do I need Claude Code?

Yes. Claude Code is Anthropic's free desktop app. LindaAI runs inside it with the Claude plan you already have — no developer setup, no extra accounts.

What does Claude cost to run LindaAI?

LindaAI runs on the Claude plan you already have — Claude Pro (currently $20/month) covers typical daily use. The Claude Code app itself is free, and there's no developer setup or pay-as-you-go tokens to wrangle. Your LindaAI purchase is one-time; Claude's plan is the only ongoing cost.

What platforms are supported?

macOS, Windows, and Linux. Cross-platform installers included in every tier.

Can I upgrade later?

Absolutely. Buy Bronze now, upgrade to Platinum later — you only pay the difference. Email support@send.lindaai-brain.com.

What does the Voice Pack actually do?

It makes LindaAI talk back. Every response she gives — emails, briefings, deal analysis, anything — gets read aloud in the voice you pick. Choose Country, Hip-Hop / Slang, or Regular pro, in male or female (6 combos total). Set it up with /voicesetup, toggle speaking on/off with /voice, pause/replay/scrub/save-to-audio/change-speed anytime. Included free with every tier.

Can I get a refund?

Yes — we stand behind LindaAI with a 14-day money-back guarantee. If it isn't right for you, email support@send.lindaai-brain.com within 14 days of purchase for a full refund. See our Refund Policy for details.

How do updates work?

Run /linda-sync anytime. New skills, updates, and agents install automatically from the LindaAI Updates Server. No re-download.
